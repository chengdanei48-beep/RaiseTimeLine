# 08. 技術理解の確認問題

RaiseTimeLine の理解度を確認するための問いかけ集(全 36 問・6 章)。

このアプリは AI を活用して実装している。目的は「自力で実装できること」ではなく、**AI の設計意図を理解し、良し悪しを判断できる力**を確認することである(特に第 3 章)。
