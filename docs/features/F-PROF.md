# F-PROF 機能定義書: プロフィール

[← 機能一覧](../02-features.md) / [要件定義書](../01-requirements.md)

## 1. 概要
ユーザーの公開プロフィール(アイコン・表示名・@ユーザーID・自己紹介・各種件数)と、そのユーザーの投稿一覧を表示する。本人は表示名・自己紹介・アイコンを編集できる。プロフィールは**フォローの入り口**でもある(F-FOLLOW)。

| 項目 | 内容 |
|---|---|
| 対象機能 | F-PROF-01 表示 / 02 編集 / 03 アイコン設定 |
| 関連画面 | S-05 プロフィール / S-06 プロフィール編集 |
| 関連API | `GET /api/users/{id}` / `PUT /api/users/me` / `GET /api/users/{id}/posts` / `POST /api/uploads/presign`(`purpose=AVATAR`) |
| 関連テーブル | users, posts, follows |
| 権限 | 閲覧: ログイン / 編集: 本人のみ(BR-10) |

## 2. 入出力項目と検証
### プロフィール取得(`GET /api/users/{id}`)
```json
{
  "id": 7, "username": "hanako", "displayName": "佐藤花子",
  "bio": "自己紹介", "avatarUrl": "https://…(署名付きURL)",
  "postCount": 24, "followingCount": 15, "followerCount": 32,
  "followedByMe": false, "isMe": false
}
```
`postCount` は削除済みを除く。**閲覧数・インプレッションに当たる項目は含めない**(BR-14)。

### プロフィール更新(`PUT /api/users/me`)
| 項目 | 必須 | 検証 |
|---|---|---|
| displayName | ○ | 前後の空白を除いて 1〜30文字 |
| bio | - | 0〜160文字(BR-09) |
| avatarKey | - | 省略=変更なし / `null`=アイコン削除 / 文字列=新アイコン。文字列は **自分が発行した `avatars/{自分のID}/` 配下**で、S3 上に存在し 2MB 以下・画像形式であること |

**ユーザーID(username)は変更できない**(ログインIDと検索・リンクの基準のため)。

## 3. 業務ルール
- 本人以外は更新できない。`PUT /api/users/me` は常にログイン中のユーザー自身を更新するため、他人を指定する経路がない。
- アイコン画像の流れは [F-POST](F-POST.md) と同じ(署名付きURL → S3 へ直接アップロード → キーを保存)。古いアイコンのオブジェクトは今回は削除しない。
- 投稿一覧(`GET /api/users/{id}/posts`)は [F-TL](F-TL.md) と同じ形式・並び・ページング。
- 自分のプロフィール(`isMe=true`)ではフォローボタンを出さず「編集」を出す。

## 4. 基本フロー
1. S-05 を開く → `GET /api/users/{id}` と `GET /api/users/{id}/posts` を取得して表示。
2. 本人は「編集」→ S-06 で表示名・自己紹介を編集、またはアイコンを選択(プレビュー)。
3. アイコン選択時は署名付きURLで S3 へアップロード → 「保存」で `PUT /api/users/me`。
4. 成功したら S-05 へ戻り、ヘッダーの表示名・アイコンも更新する。

## 5. 代替・異常フロー
| 条件 | 結果 |
|---|---|
| 存在しないユーザー | 404「ユーザーが見つかりません」 |
| 表示名が空・31文字以上、自己紹介が161文字以上 | 400 |
| 画像が形式・サイズ不正 | ブラウザ側で拒否。API でも 400 |
| 他人の `avatarKey` を指定 | 400 |
| 保存に失敗 | 入力値を保持してエラー表示 |

## 6. 受入条件
- [ ] 他人のプロフィールに、投稿数・フォロー中・フォロワーの件数とフォローボタンが表示される
- [ ] 自分のプロフィールには「編集」が表示され、フォローボタンは表示されない
- [ ] 表示名・自己紹介を更新すると、プロフィール・投稿カード・検索結果に反映される
- [ ] ユーザーID は編集画面で変更できない
- [ ] アイコンを設定・削除できる(削除後は既定のアイコン表示)
- [ ] プロフィールのどこにもインプレッション数が表示されない
