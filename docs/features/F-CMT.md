# F-CMT 機能定義書: コメント

[← 機能一覧](../02-features.md) / [要件定義書](../01-requirements.md)

## 1. 概要
投稿に対してコメント(返信)を書き込む。第三者もコメントできる。投稿ごとの**コメント数**をタイムライン・詳細に表示する。コメントへのコメント(入れ子)や編集は提供しない。

| 項目 | 内容 |
|---|---|
| 対象機能 | F-CMT-01 投稿 / 02 一覧 / 03 削除 / 04 コメント数表示 |
| 関連画面 | S-04 投稿詳細 / S-03(コメント数表示) |
| 関連API | `GET /api/posts/{id}/comments` / `POST /api/posts/{id}/comments` / `DELETE /api/comments/{id}` |
| 関連テーブル | comments |
| 権限 | 投稿・閲覧: ログイン / 削除: コメントの作成者のみ |

## 2. 入出力項目と検証
### コメント投稿(`POST /api/posts/{id}/comments`)
| 項目 | 必須 | 検証 |
|---|---|---|
| body | ○ | 前後の空白を除いて 1〜280文字(BR-03) |

応答: 201 + コメント(`id`、`body`、`createdAt`、`author`)。

### コメント一覧(`GET /api/posts/{id}/comments`)
| パラメータ | 内容 |
|---|---|
| cursor / limit | 古い順(`created_at` 昇順、`id` 昇順)。limit 既定 20、最大 50 |

応答: `{ "items": [コメント…], "nextCursor": … }`

## 3. 業務ルール
- 自分の投稿にもコメントできる(BR-07)。
- 削除は論理削除。削除したコメントは一覧・コメント数から除く。
- 親の投稿が削除済み(または存在しない)なら、投稿・一覧取得・削除のすべてが 404。
- コメント数は `COUNT(*) WHERE post_id = ? AND deleted_at IS NULL`。タイムライン取得時にまとめて集計する(F-TL)。

## 4. 基本フロー
1. S-04 でコメントを入力 → 「返信する」。
2. API が検証して `comments` に INSERT。
3. 画面は一覧の末尾にコメントを追加し、コメント数(S-04 と戻った先の S-03)を +1 する。

削除: 自分のコメントの「削除」→ 確認ダイアログ → 論理削除 → 一覧から除去、コメント数 −1。

## 5. 代替・異常フロー
| 条件 | 結果 |
|---|---|
| 本文が空・281文字以上 | 400 |
| 対象投稿が存在しない/削除済み | 404 |
| 他人のコメントを削除 | 403 |
| 削除済みのコメントを再削除 | 404 |
| 送信失敗 | 入力内容を保持したままエラー表示 |

## 6. 受入条件
- [ ] 他のユーザーの投稿にコメントでき、投稿者・他の閲覧者にも表示される
- [ ] コメント数が投稿カードに表示され、追加・削除で増減する
- [ ] 自分のコメントだけ「削除」が表示され、他人のコメントを API で削除すると 403
- [ ] 投稿が削除されると、そのコメントは表示されない
- [ ] コメント者名のクリックでプロフィールへ移動できる
