# 03. 画面設計

要件定義書([01-requirements.md](01-requirements.md))8章の補足資料です。各画面で使う機能の詳細は [features/](features/) を参照してください。

## 1. 画面一覧
| ID | 画面名 | パス | 認証 | 主な機能 |
|---|---|---|---|---|
| S-01 | 新規登録 | /signup | 不要 | F-AUTH-01 |
| S-02 | ログイン | /login | 不要 | F-AUTH-02 |
| S-03 | タイムライン | / | 必要 | F-TL-01〜04, F-POST-01〜05, F-LIKE |
| S-04 | 投稿詳細 | /posts/:id | 必要 | F-TL-05, F-CMT-01〜04, F-LIKE |
| S-05 | プロフィール | /users/:id | 必要 | F-PROF-01, F-FOLLOW-01・02・05 |
| S-06 | プロフィール編集 | /settings/profile | 必要 | F-PROF-02, 03 |
| S-07 | ユーザー検索 | /search | 必要 | F-SEARCH-01〜03, F-FOLLOW-01・02 |
| S-08 | フォロー中・フォロワー一覧 | /users/:id/following, /users/:id/followers | 必要 | F-FOLLOW-03, 04 |

`:id` は内部ID(数値)。画面上の表示は `@ユーザーID`。

共通ヘッダー(S-03〜S-08): アプリ名(→S-03) / 検索(→S-07) / 自分のアイコン・表示名(→S-05 自分) / ログアウト。

> 実装状況: 全て実装済み(ログイン後の全画面で固定表示。新規登録・ログインには出さない)。「検索」はリンクで S-07 へ移る(検索ボックスはヘッダーに置かず、S-07 の検索欄で入力する)。

## 2. 画面遷移図
```mermaid
flowchart LR
    S01[S-01 新規登録] -->|登録成功| S03
    S01 -->|ログインへ| S02[S-02 ログイン]
    S02 -->|ログイン成功| S03[S-03 タイムライン]
    S02 -->|新規登録へ| S01

    S03 -->|投稿/コメントアイコン| S04[S-04 投稿詳細]
    S04 -->|戻る / 投稿削除後| S03

    S03 -->|投稿者名・アイコン| S05[S-05 プロフィール]
    S04 -->|投稿者名・コメント者名| S05
    S03 -->|ヘッダー検索| S07[S-07 ユーザー検索]
    S04 -->|ヘッダー検索| S07
    S05 -->|ヘッダー検索| S07
    S07 -->|結果の行| S05
    S05 -->|フォロー中/フォロワー| S08[S-08 フォロー中・フォロワー一覧]
    S08 -->|行をクリック| S05
    S05 -->|投稿をクリック| S04
    S05 -->|編集(本人のみ)| S06[S-06 プロフィール編集]
    S06 -->|保存/キャンセル| S05

    S03 -->|ログアウト| S02
```
未ログインで S-03〜S-08 にアクセスした場合は S-02 へリダイレクト。アクセストークンはメモリにしか持たないため、ページを開いたとき(リロード含む)はまずリフレッシュトークン(Cookie)でログイン状態を復元し、復元できなければ S-02 へ遷移する。API が 401 を返したときは、トークンを更新して 1 回だけ再試行し、それでも 401 なら S-02 へ遷移する。

## 3. 画面詳細

### S-01 新規登録
| 項目 | 種別 | 検証 |
|---|---|---|
| ユーザーID | テキスト | 必須。3〜15文字、半角英数字と `_`。大文字小文字を区別せず重複不可 |
| 表示名 | テキスト | 必須、1〜30文字(前後の空白は除いて数える) |
| パスワード | パスワード | 必須、8〜72文字 |
| パスワード(確認) | パスワード | 必須。パスワードと一致(画面で確認) |
| 登録ボタン | ボタン | 成功時 S-03 へ(ログイン状態) |

エラー: 重複ユーザーID「このユーザーIDは既に使われています」/ 形式不正「ユーザーIDは3〜15文字の半角英数字と _ で入力してください」

### S-02 ログイン
| 項目 | 種別 | 検証 |
|---|---|---|
| ユーザーID | テキスト | 必須 |
| パスワード | パスワード | 必須 |
| ログインボタン | ボタン | 失敗時「ユーザーIDまたはパスワードが正しくありません」(どちらが誤りかは示さない) |

### S-03 タイムライン
```
+----------------------------------------------------------+
| RaiseTimeLine     [🔍 ユーザーを検索]   (●)山田太郎 [ログアウト] |
+----------------------------------------------------------+
|                                          [投稿する]      |
+----------------------------------------------------------+
|   [ フォロー中 ]   [ 全体 ]                               |
+----------------------------------------------------------+
| (●)佐藤花子 @hanako  ·  10分前                  [削除*]  |
| 今日はいい天気ですね                                      |
| [画像][画像]                                              |
| 💬 3   ♡ 12                                               |
+----------------------------------------------------------+
| ...                                                      |
|                    [ もっと見る ]                         |
+----------------------------------------------------------+
```
`*` 編集・削除は自分の投稿のみ表示。編集は投稿フォームと同じモーダルが元の本文つきで開き(「保存」「キャンセル」)、編集済みは日時の横に「(編集済み)」を表示。削除は確認(「削除する」「キャンセル」)の後に実行。

> 実装状況: 第1段階はテキストのみ(投稿への画像添付は後続。プロフィール編集 S-06(表示名・自己紹介・アイコン)は実装済み。アイコンは選択時にプレビューし、保存時に署名付き URL で S3 へ直接アップロードしてから保存する。アイコン画像(`avatarUrl`)は投稿・コメント・一覧・検索・プロフィール・ヘッダーに表示し、画像が無い・読み込めないときは表示名の頭文字の既定表示にする。ユーザー検索 S-07(検索語は URL の `?q=` に保持。未入力は案内文のみで API を呼ばない)は実装済み。タブ(「フォロー中」既定・「全体」)、プロフィール S-05(アイコンは表示名の頭文字の既定表示)、フォロー中・フォロワー一覧 S-08、フォローボタン(共通部品)は実装済み。「フォロー中」が空のときは、案内文と S-07 へのリンクを表示する。投稿者名・コメント者名・アイコンはプロフィールへのリンク。コメント数・いいね数・いいねボタンと、投稿詳細 S-04(コメントの投稿・一覧・削除)は実装済み。S-04 の投稿は削除のみで、編集はホームから行う)。投稿・投稿削除・コメント削除の完了時は、画面下に完了メッセージ(トースト。「投稿しました」など)を約 2.6 秒表示する。S-04 の「← 戻る」は直前の画面へ戻り、直接開いたときはホームへ移る。

| 要素 | 仕様 |
|---|---|
| タブ | 「フォロー中」(既定)/「全体」。選択はブラウザ内に保持してよい。切替時は先頭から再取得 |
| 投稿フォーム(モーダル) | S-03 上部の「投稿する」で開く(常設フォームは置かない)。本文必須(1〜280)、画像最大4枚、プレビュー・個別削除、残り文字数。画像は署名付きURLで S3 へ直接アップロード後、投稿作成APIにキーを渡す。投稿成功でモーダルを閉じ、一覧の先頭に追加。失敗時は開いたままエラーを表示し入力を保持。Esc・×・背景クリック・「キャンセル」で閉じ、入力が残っているときは破棄の確認をする。編集もこのモーダルを共用(初期値は元の本文、変更がないと保存できない) |
| 投稿カード | アイコン、表示名、@ユーザーID(いずれもクリックで S-05)、日時、本文、画像、**コメント数、いいね数**、いいねボタン(済みは強調) |
| いいね | クリックでトグル。件数は即時反映(楽観的更新)し、失敗時は元に戻してエラー表示 |
| コメントアイコン | クリックで S-04 へ |
| ページング | 20件ずつ。**無限スクロール**(末尾に近づくと次の20件を自動取得。最後まで読むと止まる)。取得に失敗したら自動取得を止め、「もっと見る」ボタンで再試行 |
| 新着バナー | 30秒ごとに先頭ページを取得し、表示中の最新より新しい他ユーザーの投稿があれば「N件の新しい投稿を表示」(20件以上は「20件以上の」)をバナー表示。クリックで一覧の先頭に追加して先頭へスクロール(20件以上のときは、取りこぼしを避けるため、一覧を先頭から取得し直して置き換える。失敗時はエラーを表示しバナーを保持)。タブが非表示の間は取得しない。自分の投稿は即時に先頭へ追加されるためバナーに含めない |
| 空表示(フォロー中) | フォロー中の人がいない・投稿がないとき「まだ投稿がありません。ユーザーを検索してフォローしてみましょう」+ S-07 へのリンク |
| 非表示項目 | インプレッション数、リポスト/引用のボタンは**表示しない** |

### S-04 投稿詳細
```
+----------------------------------------------------------+
| ← 戻る                                                   |
| (●)佐藤花子 @hanako · 10分前                     [削除*]  |
| 今日はいい天気ですね                                      |
| [画像][画像]                                              |
| 💬 3   ♡ 12                                               |
+----------------------------------------------------------+
| [ コメントを入力 (280字)                  ] [返信する]    |
+----------------------------------------------------------+
| (●)田中次郎 @jiro · 5分前                        [削除*]  |
| 本当ですね!                                              |
+----------------------------------------------------------+
```
| 要素 | 仕様 |
|---|---|
| コメント入力 | 必須、1〜280字。投稿後に一覧へ即時追加し、コメント数+1 |
| コメント一覧 | 古い順。コメント者のアイコン・名前はクリックで S-05。自分のコメントのみ削除可 |
| 存在しない/削除済みの投稿 | 「投稿が見つかりません」を表示し S-03 へ誘導 |

### S-05 プロフィール
```
+----------------------------------------------------------+
| ← 戻る                                                   |
| (アイコン)  佐藤花子  @hanako          [フォロー中 ✓]    |
| 自己紹介テキスト(最大160字)             (本人: [編集])  |
| 投稿 24   フォロー中 15   フォロワー 32                   |
+----------------------------------------------------------+
| (投稿カード:S-03 と同じ。そのユーザーの投稿のみ)        |
|                    [ もっと見る ]                         |
+----------------------------------------------------------+
```
| 要素 | 仕様 |
|---|---|
| フォローボタン | 他人のプロフィールに表示。未フォロー「フォローする」/ フォロー済み「フォロー中」(押すと解除)。自分のプロフィールには表示せず「編集」を表示。押下で件数(フォロワー)も即時更新 |
| 件数 | 「フォロー中」「フォロワー」はクリックで S-08。投稿数は削除済みを除く |
| 存在しないユーザー | 「ユーザーが見つかりません」 |
| 非表示項目 | インプレッション数は表示しない |

### S-06 プロフィール編集
| 項目 | 種別 | 検証 |
|---|---|---|
| アイコン画像 | ファイル | 任意、JPEG/PNG/GIF/WebP、2MB以下、プレビュー・削除可。署名付きURLで S3 へ直接アップロード |
| 表示名 | テキスト | 必須、1〜30文字 |
| 自己紹介 | テキストエリア | 任意、160文字以内 |
| ユーザーID | 表示のみ | **変更不可** |
| 保存ボタン | ボタン | 成功時 S-05 へ |

### S-07 ユーザー検索
```
+----------------------------------------------------------+
| ← 戻る                                                   |
| [ ユーザーIDまたは表示名で検索           ] [検索]        |
+----------------------------------------------------------+
| (●)佐藤花子  @hanako                    [フォローする]   |
| 自己紹介の先頭部分…                                      |
+----------------------------------------------------------+
| (●)花山太郎  @hanayama                  [フォロー中 ✓]   |
+----------------------------------------------------------+
|                    [ もっと見る ]                         |
+----------------------------------------------------------+
```
| 要素 | 仕様 |
|---|---|
| 検索欄 | ユーザーID・表示名の部分一致(大文字小文字を区別しない)。1〜50文字。Enter または「検索」で実行。先頭の `@` は無視する。前後の空白は除く |
| 結果 | 20件ずつ。**自分は含めない**。並びはユーザーID昇順。行クリックで S-05、ボタンでフォロー/解除 |
| 未入力 | 検索を実行せず、案内文「ユーザーIDまたは表示名を入力してください」を表示 |
| 0件 | 「該当するユーザーが見つかりません」 |

### S-08 フォロー中・フォロワー一覧
| 要素 | 仕様 |
|---|---|
| タブ | 「フォロー中」「フォロワー」(パスで切替)。見出しに対象ユーザーの表示名 |
| 行 | アイコン、表示名、@ユーザーID、フォローボタン(自分の行には表示しない)。クリックで S-05 |
| ページング | 20件ずつ。新しくフォローした順 |
| 0件 | 「まだいません」 |

## 4. 共通エラー表示
| 状況 | 表示 |
|---|---|
| 認証切れ (401) | トークンを更新して 1 回再試行。更新できなければ S-02 へ遷移 |
| 権限なし (403) | 「この操作は許可されていません」 |
| 対象なし (404) | 各画面の「見つかりません」表示 |
| 通信/サーバーエラー | 「しばらくしてから再度お試しください」 |
